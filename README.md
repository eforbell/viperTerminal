# Viper Terminal

A personal Bloomberg-like terminal for stock and crypto quotes with a beautiful console UI.

## Installation

```bash
pip install -e ".[dev]"
```

## Usage

```bash
python -m viper
# or
viper
```

## Development

### Run tests
```bash
pytest
```

### Type checking
```bash
mypy viper
```

### Linting
```bash
ruff check .
```

## Keybindings

- `q` - Quit application
