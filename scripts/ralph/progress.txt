# Feature 3: Data Reliability & Chart Improvements - Progress Log

## Codebase Patterns

### From Features 1 & 2 (Reference AGENTS.md for full details)
- **Virtual Environment**: Always use `.venv/bin/python` for commands
- **Async Testing**: Use `@pytest.mark.asyncio` with `asyncio_mode = "auto"`
- **Textual Testing**: Use `async with app.run_test() as pilot` pattern
- **External APIs**: Always mock yfinance in tests
- **Type Checking**: `mypy --strict` requires explicit annotations everywhere
- **Coverage**: Maintain 90%+ test coverage
- **Event Handlers**: Use `on_{widget_name}_{event_name}` pattern (snake_case)
- **Custom Events**: Define as nested classes inheriting from `Message`
- **Panel Toggle Pattern**: Use `styles.display = "block"/"none"` for visibility
- **Focus Management**: Set `can_focus = True` and use `priority=True` on bindings
- **Responsive Layout**: Use `on_resize()` handler (no @media queries in TCSS)
- **Period Mapping**: User-friendly periods (1W, 1M) map to yfinance periods via dicts
- **Volume Integer Conversion**: Convert pandas volume to int: `[int(v) for v in hist["Volume"].tolist()]`
- **Mock DataFrames**: Use `pd.DataFrame` with `pd.date_range` index for realistic test mocks

### New Patterns for Feature 3 (Add as discovered)
- **yfinance News**: Use `ticker.news` attribute, returns list of dicts with `content.title`, `content.summary`, etc.
- **yfinance Crypto**: Use SYMBOL-USD format (BTC-USD, ETH-USD) for crypto via yfinance
- **Chart Interpolation**: When data < 60% of chart width, price chart upsamples - volume must match
- **Technical Indicators**: Pure calculation functions, return None for initial values where calculation not possible
- **Indicator Panels**: Use IndicatorPanel base class for oscillator indicators (RSI, MACD, etc.)
- **Reference Lines**: HorizontalLine dataclass with value, label, style, color for level markers
- **Explicit Type Hints**: Always add explicit type annotations to attributes (self._name: str = name)
- **Braille Indicators**: Use dots 7+8 for simpler indicator line vs full vertical lines for price chart
- **Unicode Box Drawing**: "─" (solid), "┄" (dashed), "┈" (dotted) for reference lines

## 2026-01-07 - VPR-037
- **What was implemented**: Relative Strength Index (RSI) indicator calculation service using Wilder's smoothing
- **Files changed**:
  - `viper/services/indicators.py`: Added calculate_rsi() function with Wilder's smoothing method
  - `tests/test_indicators.py`: Added 24 comprehensive tests for RSI calculation
  - `scripts/ralph/features/feature-3-prd.json`: Marked VPR-037 as complete
  - `AGENTS.md`: Added VPR-037 learnings section with 38 detailed points
- **Learnings**:
  - **RSI Formula**: RSI = 100 - (100 / (1 + RS)) where RS = Average Gain / Average Loss
  - **Wilder's Smoothing Critical**: Use Wilder's smoothing for averages, NOT simple moving average
  - **Two-stage averaging**: First avg = simple average of first period, then Wilder's smoothing for rest
  - **Wilder's Formula**: ((prev_avg * (period-1)) + current_value) / period
  - **Default Period 14**: Industry standard for RSI, included as default parameter
  - **Return Type Pattern**: Use `list[float | None]` to match SMA/EMA interface consistency
  - **None Count Difference**: RSI returns `period` Nones (not period-1 like MA indicators)
  - **Reason for More Nones**: Need period+1 prices total (period deltas, then period for first avg)
  - **Delta Calculation**: Pre-calculate all deltas first: `prices[i] - prices[i-1]`
  - **Separate Gains/Losses**: Extract gains with `max(delta, 0.0)`, losses with `abs(min(delta, 0.0))`
  - **Initial Lists**: Create separate initial_gains and initial_losses lists from first period deltas
  - **First Averages**: Calculate avg_gain and avg_loss from initial lists using simple average
  - **First RSI Index**: Calculate first RSI at index `period` (need period+1 prices for first RSI)
  - **Division by Zero Handling**: Check `if avg_loss == 0.0`, return RSI = 100.0 (infinite RS)
  - **All Losses Case**: If avg_gain == 0.0, RS = 0, RSI = 100 - (100/1) = 0.0
