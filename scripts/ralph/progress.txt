### Learnings
- **Type Overloading**: Used `@overload` decorator for _downsample method to preserve type safety (list[float] vs list[datetime])
- **Downsampling Gotcha**: Must use original data for min/max to avoid losing extremes during downsampling
- **Type Narrowing**: Required `cast()` and `isinstance()` checks to help mypy understand type narrowing in generic functions
- **Multi-Line Returns**: When functions return strings with `\n`, use `.split("\n")` and `.extend()` not `.append()`
- **Braille Unicode**: Range U+2800-U+28FF provides 256 patterns (2 columns × 4 rows of dots per character)
- **Braille Dot Mapping**: Left column uses dots 1-3,7; right column uses dots 4-6,8
- **Chart Dimensions**: Subtract axis widths from total dimensions before rendering chart area
- **Normalization Formula**: `(value - min) / (max - min)` maps to 0-1, then scale to target resolution
- **Even-Spaced Downsampling**: `step = len(data) / target; sampled = [data[int(i * step)] for i in range(target)]`
- **Floating Point Tests**: Use epsilon tolerance (0.011) instead of exact equality for float comparisons
- **Edge Case Testing**: 29 tests covering empty data, single point, flat lines, zigzag, negative prices, large ranges
- **Dataclass Pattern**: RenderedChart dataclass cleanly returns multiple related values (lines, dimensions, min/max)
- **Type Assertions**: Add `assert isinstance()` checks when downcasting union types to help mypy

- Focus was on core rendering quality and comprehensive testing
- Both rendering styles (Braille and Block) fully functional and tested
