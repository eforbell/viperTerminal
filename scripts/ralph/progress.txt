# Feature 3: Data Reliability & Chart Improvements - Progress Log

## Codebase Patterns

### From Features 1 & 2 (Reference AGENTS.md for full details)
- **Virtual Environment**: Always use `.venv/bin/python` for commands
- **Async Testing**: Use `@pytest.mark.asyncio` with `asyncio_mode = "auto"`
- **Textual Testing**: Use `async with app.run_test() as pilot` pattern
- **External APIs**: Always mock yfinance in tests
- **Type Checking**: `mypy --strict` requires explicit annotations everywhere
- **Coverage**: Maintain 90%+ test coverage
- **Event Handlers**: Use `on_{widget_name}_{event_name}` pattern (snake_case)
- **Custom Events**: Define as nested classes inheriting from `Message`
- **Panel Toggle Pattern**: Use `styles.display = "block"/"none"` for visibility
- **Focus Management**: Set `can_focus = True` and use `priority=True` on bindings
- **Responsive Layout**: Use `on_resize()` handler (no @media queries in TCSS)
- **Period Mapping**: User-friendly periods (1W, 1M) map to yfinance periods via dicts
- **Volume Integer Conversion**: Convert pandas volume to int: `[int(v) for v in hist["Volume"].tolist()]`
- **Mock DataFrames**: Use `pd.DataFrame` with `pd.date_range` index for realistic test mocks

### New Patterns for Feature 3 (Add as discovered)
- **yfinance News**: Use `ticker.news` attribute, returns list of dicts with `content.title`, `content.summary`, etc.
- **yfinance Crypto**: Use SYMBOL-USD format (BTC-USD, ETH-USD) for crypto via yfinance
- **Chart Interpolation**: When data < 60% of chart width, price chart upsamples - volume must match
- **Technical Indicators**: Pure calculation functions, return None for initial values where calculation not possible
