# Ralph Progress Log

## Codebase Patterns
- **Virtual Environments**: System Python is externally managed - always use `python3 -m venv .venv`
- **pytest-asyncio**: Set `asyncio_mode = "auto"` in pyproject.toml for auto-detection
- **Textual Testing**: Use `async with app.run_test()` (omit `as pilot` if not using it)
- **Coverage**: Entry points like `__main__.py` need explicit tests with mocked instances
- **mypy --strict**: Requires all function signatures to have type annotations
- **.gitignore**: Don't forget to exclude .venv/ directory
- **Textual Events**: Define custom events as nested classes inheriting from `Message`
- **Event Handlers**: Use `on_{widget_name}_{event_name}` pattern (snake_case)
- **Input Validation**: Always strip whitespace before validation; clear value even on error
- **CSS Classes**: Use `add_class()` / `remove_class()` for dynamic styling (error states)
- **Test Event Tracking**: Store events in test app's instance variable for verification
