

## 2026-01-22 - VPR-097
- **What was implemented**: StreamingService singleton for WebSocket-based real-time quote streaming
- **Files changed**:
  - `viper/services/streaming.py`: Created StreamingService, StreamingQuote, ConnectionState (160 lines)
  - `viper/services/__init__.py`: Added "streaming" to exports
  - `tests/test_streaming.py`: 42 comprehensive tests with 100% coverage
  - `AGENTS.md`: Added VPR-097 learnings section
  - `scripts/ralph/features/feature-12.prd.json`: Marked VPR-097 complete
- **Learnings**:
  - **Singleton with testing**: Use `_reset_instance()` class method to allow tests to get fresh instances
  - **AsyncMock for WebSocket**: Mock async methods with `AsyncMock()`, not `MagicMock()` for proper async behavior
  - **Mock listen() carefully**: Use custom async function with `asyncio.sleep()`, not just AsyncMock, to control when loop runs
  - **Give async tasks time**: Use `await asyncio.sleep(0.05)` after `start()` to let listen task spawn before assertions
  - **Callback vs Message separation**: Service uses callbacks (runs in any context), UI layer converts to Textual messages
  - **Error handling philosophy**: Log and continue for subscription errors, log and reconnect for connection errors, re-raise for start failures
  - **Idempotent operations**: stop() when not running is safe, subscribe() with duplicates is safe, unsubscribe() with non-existent is safe
  - **yfinance AsyncWebSocket**: Handles heartbeat (15s) and reconnect with exponential backoff automatically
  - **Symbol normalization must be idempotent**: BTC-USD → BTC-USD (don't double-convert)
  - **100% coverage requires edge cases**: Test "no-op" paths (empty lists, stop when not running, subscribe when not running, etc.)
  - **Type checking yfinance**: Requires `# type: ignore[import-untyped]` on import (follows pattern from crypto.py, stock.py, news.py)
  - **WebSocket message parsing**: Extract `id` or `symbol`, `price`, calculate change from `previousClose`, default to 0.0 if missing
  - **State management**: Use enum for clear state transitions, notify via callback when state changes
  - **Lifecycle**: start() spawns listen task, stop() cancels task and closes connection, listen loop handles reconnect
  - **Subscription management**: Normalize symbols, deduplicate, maintain internal set, call WebSocket subscribe/unsubscribe
  - Coverage: 100% on streaming.py (42 tests), 87% overall (1067 tests passing)

## 2026-01-22 - VPR-098
- **What was implemented**: Integrated streaming toggle into WatchlistPanel with thread-safe message handling
- **Files changed**:
  - `viper/widgets/watchlist_panel.py`: Added streaming integration (100 new lines, 212 total, 92% coverage)
  - `tests/test_watchlist_panel.py`: Added 11 comprehensive streaming tests (38 total tests, all passing)
  - `AGENTS.md`: Added VPR-098 learnings section (60 lines)
  - `scripts/ralph/features/feature-12.prd.json`: Marked VPR-098 complete
- **Learnings**:
  - **app.call_from_thread()**: CRITICAL for posting Textual messages from WebSocket/async callbacks running in different contexts
  - **Callback-to-message bridge pattern**: WebSocket callback stores data + posts message via `call_from_thread()`, message handler triggers UI update
  - **Singleton testing limitation**: Can't patch class methods after singleton instance exists - must mock instance directly (`panel._streaming_service = MagicMock()`)
  - **run_worker() pattern**: Use to call async methods from sync contexts (like button/keybinding handlers calling `toggle_streaming()`)
  - **Polling as failsafe**: Don't stop polling when streaming enabled - streaming may not have all data immediately or could disconnect
  - **Data preference order**: Check `_streaming_quotes` first in `_render_items()`, fall back to `_quotes` for robustness
  - **Header updates in _render_items()**: Update header based on `_connection_state` inside render method to keep in sync with data, prevents flickering
  - **Message handler naming convention**: `on_<widget_name>_<message_name>` (e.g., `on_watchlist_panel_streaming_quote_received`)
  - **Textual Label text access**: Use `str(label.render())`, not `label.renderable` (doesn't exist)
  - **Textual pilot testing**: Use `await pilot.pause()` to give event loop time to process messages before assertions
  - **Streaming subscription lifecycle**: On ticker add, subscribe to streaming if active; on remove, unsubscribe if active
  - **Error handling in enable**: Catch exceptions, notify user, stay in polling mode - streaming failure shouldn't break app
  - **State tracking**: Maintain `_connection_state` separately from service state for UI updates even when service is stopped
  - Coverage: 92% on watchlist_panel.py (16 uncovered lines, mostly error handling), 87% overall (1077 tests passing)
